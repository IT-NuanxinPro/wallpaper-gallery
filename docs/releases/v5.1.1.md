# v5.1.1

修复图片预览、下载计数及热门榜单的数据口径，并改善首屏加载和连续浏览体验。

## 统计与数据

- 下载固定点击时的资源；只有浏览器已发起下载或原生下载确认完成才记录，失败和备用链接打开不再误计。
- 图片、视频就绪后记录预览，详情切图正确计数；同一会话短时间重复预览去重，网络重试复用事件 ID。
- 全量分页导出统计，校验总条数与期间边界；取消浏览量前 500 张截断造成的统计缺失。
- 本周、本月热门按北京时间对应期间的实际互动排序，旧图片也可参与；显示期间统计开始时间与快照更新时间。
- 资源、喜欢、收藏及下载历史使用完整资源身份，分离同系列重名图片；无法准确拆分的旧累计数据单独保留。
- 收紧用户资料的角色与状态字段权限，增加事件、每日统计及相关访问控制。

## 加载与交互

- 首屏先显示最新切片，完整目录后台补齐；筛选等待完整结果，补全失败可重试。
- 缩略图和预览图接入本站图片入口，支持缓存、超时与同尺寸备用地址；修复特殊字符路径编码。
- Vue 启动依赖随站点打包，不再等待 unpkg 外部脚本。
- 统一四色圆环 loading，固定加载前后尺寸，改善桌面、手机和深色模式下的弹窗体验。
- 卡片采用一次轻量上滑，保留图片懒加载；图片解码完成后淡入，避免整卡透明度动画导致闪屏。
- 改进触底分页、键盘操作、焦点、忙碌与路由反馈，并支持减少动态效果。

## 升级说明

- 本次数据库与前端需要配套升级，旧页面请刷新；使用旧页面的桌面客户端请重新加载。
- 下载量表示“下载已发起”，不代表浏览器最终写入磁盘成功；图片预览量与网站 PV/UV 分开。
- 周/月互动统计从新机制启用后开始积累，不补造过去的每日数据。
- 保留历史累计与用户关系，迁移前在数据库内部创建非公开备份。

验证覆盖自动化回归、生产构建、图片入口及本地数据库迁移、权限与幂等检查。
