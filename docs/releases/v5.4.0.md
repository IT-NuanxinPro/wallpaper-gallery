# v5.4.0

壁纸详情成为独立网页，浏览、分享与搜索访问使用同一个稳定地址。

## 浏览与详情

- 点击壁纸图片或标题进入真实详情页，支持新标签页打开；独立“快速预览”按钮保留弹窗浏览。
- 详情页统一高清预览、下载、复制链接、智能裁剪及客户端设置壁纸操作，并展示真实尺寸、格式、文件大小与来源信息。
- 新增面包屑和相关壁纸链接，返回列表恢复原筛选、已展开数量与滚动位置。
- 所有设备均可浏览电脑、手机、头像、Bing 和视频分类；首页保持稳定地址，不再根据设备跳转。

## 搜索与分享

- 首页、分类与专题提供预渲染 HTML；详情由边缘函数输出正文、独立标题、描述、规范地址及结构化数据，无需先执行 JavaScript。
- 标题清理文件扩展名和分隔符，按图片事实生成中文分类词；保留原始描述，不虚构作者或授权。
- 站点地图随真实资源同步生成，覆盖所有有效详情、分类和专题；只在有可信日期时提供更新时间。
- 统一无尾斜杠地址，修复全局重写与静态资源的冲突；无效详情和未知地址返回真实 404，临时服务错误返回 503。
- 缩略图和预览图继续使用本站图片入口，Bing 与视频保留既有源站。

## 升级说明

本次为网站更新 v5.4.0，刷新页面即可生效；桌面客户端版本保持 v5.3.0，无需重新安装。没有数据库结构或图床资源迁移。

搜索平台的抓取与提交结果会分别核验；提交链接不代表立即收录，最终索引由 Google、百度决定。
