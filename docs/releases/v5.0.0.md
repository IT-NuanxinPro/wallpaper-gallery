# Wallpaper Gallery v5.0.0

Wallpaper Gallery 5.0.0 是一次面向桌面体验与分发方式的主要版本升级。本版本在保持 Web 端轻量更新能力的基础上，正式补齐桌面客户端下载入口、Pake/Tauri 桌面端下载兼容以及第三方 OAuth 授权导航体验。

## ✨ 主要更新

### 1. 首页新增桌面客户端下载入口

桌面端首页导航栏在搜索按钮之后新增客户端入口，采用与账号头像菜单一致的毛玻璃悬浮下拉设计。

当前提供三个直接下载入口：

- **macOS 客户端**：Universal DMG，同时支持 Apple Silicon 与 Intel Mac
- **Windows 客户端**：x64 MSI 安装包
- **Linux 客户端**：x86_64 AppImage

下拉菜单支持浅色 / 深色主题，并对悬停、聚焦和点击反馈进行了统一设计。

> 首页不单独展示 Linux DEB 项，避免同一平台出现重复选择；DEB 包仍可作为桌面 Release 的补充分发产物保留。

### 2. 桌面端第三方登录增加授权导航

针对 Pake 桌面客户端内进行 GitHub、Google、Linux.do 等第三方 OAuth 授权时，用户进入第三方页面后缺少明显返回入口的问题，新增桌面授权导航层。

授权页面会显示：

- **返回**：返回上一页，不再让用户被困在第三方授权页面
- **当前授权平台 / 域名提示**：明确当前正在进行安全授权
- **取消**：退出本次授权并返回 Wallpaper Gallery 登录页
- **Esc 取消支持**：桌面键盘操作更直接

授权流程仍在 Pake WebView 内完成，避免简单跳转系统浏览器后产生浏览器与客户端登录态隔离的问题。

### 3. 优化 Pake / Windows 壁纸下载可靠性

桌面客户端中的壁纸下载现在优先调用 Pake/Tauri 原生 `download_file` 能力，由 Rust 直接将真实 HTTP(S) 资源写入操作系统 Downloads 目录。

这次调整重点解决：

- Windows WebView2 下 Blob 下载偶发没有生成文件的问题
- Blob URL 在下载真正开始前被过早释放的时序风险
- macOS 与 Windows 下载行为不一致的问题

普通浏览器仍保留原有 Blob 下载方式，同时延迟释放 Blob URL，作为兼容与降级路径。

### 4. 桌面客户端与网站版本正式解耦

Wallpaper Gallery 桌面端本质上是加载线上站点的轻量 Pake/Tauri 壳，因此网站 UI、壁纸数据、业务逻辑和普通前端修复无需每次重新构建桌面安装包。

从本版本开始：

- Web 版本继续按 `v5.0.0` 等语义化版本发布
- 桌面安装包使用独立稳定通道 `desktop`
- 只有桌面壳、图标、授权注入、原生能力等变化时才重新构建
- 桌面客户端重新构建后覆盖稳定 Release 中已有安装包，而不是为每个 Web 版本重复生成安装包

稳定桌面产物文件名：

- `Wallpaper-Gallery-macOS-universal.dmg`
- `Wallpaper-Gallery-Windows-x64.msi`
- `Wallpaper-Gallery-linux-x86_64.AppImage`
- `Wallpaper-Gallery-linux-x86_64.deb`

### 5. 桌面构建策略优化

桌面构建仍保留手动触发能力，同时在真正影响桌面壳的文件发生变化时自动重新构建，例如：

- Pake 授权导航注入脚本
- App 图标
- Desktop workflow 配置

这样既避免普通网站更新浪费三平台 GitHub Actions，又能保证桌面原生能力发生变化后及时生成最新安装包。

## 🎨 体验细节

- 客户端下载菜单与账号头像菜单保持统一的圆角、毛玻璃、阴影和层级语言
- macOS / Windows / Linux 使用清晰的平台图标与安装包格式说明
- 下载入口放在搜索按钮之后，符合高频工具区的操作顺序
- 深色模式下重新适配菜单背景、图标、文字与 Hover 状态
- 桌面 OAuth 导航采用浮层形式，不修改第三方页面自身业务 DOM

## 🔄 从 v4.0.2 升级

### 浏览器用户

无需操作。网站部署完成后刷新页面即可使用 5.0.0。

### 已安装桌面客户端的用户

网站层面的 5.0.0 功能会随线上站点更新自动加载，无需因为普通页面变化重新安装。

不过，本版本新增的 **OAuth 授权返回 / 取消导航属于桌面壳注入能力**。如果需要这一能力，请安装本次重新构建后的 Desktop 稳定版一次。之后普通网站更新仍无需重复安装。

## 📦 下载说明

网站导航栏中的 macOS、Windows、Linux 下载按钮均指向 Wallpaper Gallery 的稳定 Desktop Release。

Web 版本 Release `v5.0.0` 用于记录网站版本、变更内容和源码快照；桌面安装包则维护在独立的 `desktop` Release 中。

## 🛠 技术说明

- Web：Vue 3 + Vite
- 桌面壳：Pake + Tauri
- 默认桌面窗口尺寸：1600 × 900
- 桌面页面来源：`https://wallpaper.061129.xyz/`
- 桌面下载目录：系统默认 Downloads
- 第三方授权：继续使用应用内 OAuth 流程，避免系统浏览器与 WebView Session 隔离

## ⚠️ 已知说明

- macOS / Windows 的操作系统安全策略可能对未签名或未公证安装包显示安全提示，这与网站本身无关。
- 桌面下载入口依赖稳定 `desktop` Release 中对应平台安装包；桌面构建完成后安装包会自动更新到该 Release。
- Linux 首页仅提供 AppImage 直接入口，DEB 用户可前往 Desktop Release 获取 `.deb` 文件。
