# Wallpaper Gallery v5.0.1

Wallpaper Gallery 5.0.1 是一次移动端弹窗体验修复，重点解决小屏和横屏场景下弹窗超出屏幕、预览区域占位过大以及底部操作难以触达的问题。

## 🐛 修复内容

### 1. 手机壁纸与头像弹窗适配

- 根据浏览器可见高度限制弹窗尺寸，并为刘海、屏幕边缘和底部手势区域预留空间。
- 内容在弹窗内部滚动，关闭按钮保持在外层，长内容和矮屏场景下也能关闭弹窗。
- 手机壁纸预览随可见高度调整，避免图片挤占底部信息与操作区域。
- 修复未登录时头像下载按钮的布局，恢复小屏上的下载文字，并允许操作按钮换行。

### 2. 动态壁纸弹窗布局修复

- 统一适配电脑动态壁纸、手机动态壁纸和朋友圈动态背景在手机上的预览布局。
- 修正播放器内部固定最小高度导致的过大占位，按预览框比例展示视频。
- 手机横屏继续使用移动端布局，详情与下载入口可通过内部滚动访问。

### 3. 筛选、分类与搜索弹层优化

- 筛选与分类弹层使用动态视口高度，改善浏览器工具栏变化和横屏时的空间分配。
- 筛选确认区域保持可用，分类列表在有限高度内滚动。
- 搜索输入区域允许收缩，避免挤出窄屏。

## 🎨 体验细节

- 放大手机壁纸和头像弹窗的关闭按钮点击区域。
- 真机预览随横竖屏变化重新计算模拟手机框尺寸。
- 移除预览尺寸变化时不必要的高度动画，减少旋转屏幕时的布局跳动。
- 保留关闭弹窗后恢复页面原有滚动位置的行为。

## 🛠 验证说明

- 生产构建与修改文件的 ESLint 检查通过。
- 浏览器模拟检查覆盖 320、375、390 像素竖屏和 844 × 390 横屏，验证弹窗边界、关闭与下载入口、触摸滚动及页面滚动恢复。
- 检查三类动态壁纸、真机预览、筛选、分类、搜索弹层，并回归桌面视频弹窗布局。
- 尚未进行 iOS / Android 真机验证。
- 现有单元测试 28 项通过；2 项图片备用地址测试仍断言已移除的 `wsrv.nl` 代理，与本次弹窗修改无关。

## 🔄 从 v5.0.0 升级

网站部署完成后刷新页面即可使用 5.0.1。本次为 Web 页面修复，已安装的桌面客户端随线上站点更新，无需重新安装。
