# v5.1.2

修复预览图加载慢或失败时“智能裁剪”无法点击的问题，完善 Windows 桌面客户端的系统主题同步。

## 智能裁剪

- 裁剪入口只依赖原图地址，不再等待预览图加载成功。
- 裁剪器独立加载原图，原图就绪后再启用裁剪下载。

## 系统主题

- 区分“跟随系统”的用户设置与当前实际深浅色，避免桌面壳把系统主题固定为手动颜色。
- 系统颜色变化时使用最新事件值，页面恢复显示时重新同步。
- 桌面壳支持清除原生主题覆盖，手动深浅色可切回跟随系统。

## 升级说明

- 网站用户刷新页面即可获得裁剪入口修复。
- Windows 完整修复需要安装重新构建的桌面客户端，仅刷新旧客户端内的网页不足以更新桌面壳。
- 新安装包以 `desktop` Release 的发布时间为准。

验证：网站 265 项自动化测试、生产构建和改动源码 lint 通过；桌面注入脚本 3 项测试通过。Windows 原生构建由 CI 验证，尚无 Windows 实机验证。
