# v5.2.0

让找图、连续浏览、分享和应用到设备形成完整流程。

## 浏览与找图

- 收紧公告与热门区，基础筛选栏数量和控件对齐；窄窗口自动换行。
- 搜索建议与结果统一匹配标题、标签和描述，精确选图使用完整资源身份。
- 上下张沿当前筛选结果切换，仅预加载相邻预览。URL 保存搜索、精确身份和打开图片，返回恢复分页与浏览位置。

## 图片、分享与专题

- 原图增加受限自有入口、正文超时、取消与备用来源；裁剪重试保留用户设置，旧请求不会覆盖新图。
- 新增可直接打开的单图站内详情与分享链接，提供真实标题、封面元信息及相关内容。
- 新增“静夜留白”“山间晨光”“海岸来信”三个精选专题与五组电脑/手机主题搭配；未知作者和授权不作推断。
- 新详情与专题的游客喜欢/收藏提供登录引导，并保留返回地址。

## 裁剪与桌面客户端

- 保留原有比例预设、自定义尺寸与实时裁剪预览，导出前校验画布大小并明确提示超限。
- 新桌面壳支持静态 JPG/JPEG/PNG 一键应用、恢复上次应用的壁纸、从现有收藏显式开启定时轮换及按需离线缓存。
- 退出客户端后停止轮换；托盘运行时继续。首次未缓存图片需要网络，不自动开启系统自启动。
- 新原生能力需要升级客户端；Bing、WebP、动态壁纸暂不支持原生设置。

## 版本通知

- 网页进入后检查更新，在可见状态每十分钟检查一次，返回页面时节流检查；提示刷新更新。
- 桌面客户端独立检查已发布安装包版本，旧版本显示下载安装及更新说明；全部平台安装包上传完成后才开放升级提醒。
- 客户端隐藏“下载客户端”图标，在标题下显示已安装版本；点击可查看网页版本并手动检查更新。旧壳无法提供版本时明确标为旧版客户端。
- 支持按更新类型和版本选择稍后提醒，不自动刷新或安装。

## 验证边界

网页已进行自动化测试、生产构建、专题预渲染与本地浏览器/Cloudflare运行验证。原生逻辑测试、macOS编译及严格检查通过；未实际更换用户系统壁纸，Windows/Linux真实运行需安装包验收。本次无数据库结构迁移。
