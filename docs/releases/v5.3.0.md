# v5.3.0

改善客户端启动体验，让已经保存的壁纸看得见、找得到、方便整理。

## 客户端启动

- Windows、macOS 和 Linux 客户端新增内置品牌启动画面与轻量加载动画，启动画面无需联网。
- 页面完成初始渲染后平滑淡出进入，不等待全部图片加载；支持深浅色和系统减少动态效果设置。
- 连接较慢时提供重新连接操作，保留托盘隐藏、窗口恢复和登录弹窗行为。

## 本地壁纸与保存位置

- 新增“本地壁纸”页面，可查看图片、大小和保存位置，重新设置壁纸、定位文件、删除或清理未使用图片。
- 最近应用、上一张及轮换使用中的图片受到保护；通过禁用按钮和悬停提示表达限制，保持卡片整齐。
- 默认保存到系统“图片/Wallpaper Gallery”，支持选择其他保存位置；Windows 使用系统图片目录，兼容 OneDrive 和目录重定向。
- 升级和更改目录时复制并校验受管图片，保留旧目录副本；内部状态文件与图片分开保存，不自动更换当前系统壁纸。
- 图片目录取消按缓存容量自动淘汰，由用户在本地壁纸页面主动整理。

## 下载与操作反馈

- 网页下载菜单显示各平台已发布的客户端版本和发布日期。
- 图片弹窗统一设壁纸、下载及辅助操作的按钮样式和布局；设置过程中使用居中的加载反馈。
- 本地图库适配桌面和窄窗口，文件定位使用对应平台的访达或文件资源管理器。

## 升级说明

启动画面和本地图片管理需要安装 v5.3.0 客户端。全部平台安装包发布完成后，现有客户端会按已有版本检查机制提示更新；网页更新可刷新生效。

原生逻辑与网页自动化检查已通过，真实设备的冷启动、断网及目录迁移表现仍需安装后验证。网页手动主题与系统主题不同时，最早启动画面可能先采用系统主题。本次无数据库结构迁移。
