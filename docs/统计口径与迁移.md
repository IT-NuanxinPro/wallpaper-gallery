# 统计口径与资源身份

校对日期：2026-11-11。自 v5.1.1 起事件、资源身份和期间榜单采用统计 v2；v5.5.0 增加单图实时汇总展示。

## 指标

| 指标 | 实际含义 |
| --- | --- |
| 网站 PV/UV | 网站分析服务的访问指标，不等于图片浏览量 |
| 浏览 | 图片解码成功或视频实际播放后的预览次数；同会话同资源 10 分钟内去重 |
| 下载 | 浏览器已触发下载或原生桥确认保存的次数；无法证明浏览器最终保存到磁盘 |
| 喜欢 | 当前账号喜欢关系维护的汇总，取消喜欢会影响当前数量 |
| 收藏 | 收藏条目的汇总；不直接宣称跨收藏夹去重后的账号人数 |

失败、空文件、错误页及仅打开备用链接不产生有效下载统计。事件重试复用 ID，服务端幂等、会话窗口和请求上限共同控制重复；匿名会话标识不等于可靠用户身份。

本周、本月热门使用北京时间周一、每月一日起的预览和下载增量，分数为 `views + 2 × downloads`，与壁纸上传日期无关。历史累计保留，期间统计只从新机制启用后积累，不能反推缺失的每日数据。

## 资源身份

- 静态图片和视频：`series:path:<规范化完整资源路径>`，每段统一编码。
- Bing：`bing:bing-YYYY-MM-DD.jpg`，与其官方图片 URL 的名称无关。
- 展示名称优先 `displayTitle`，回退 `title` / `filename`；去文件后缀只改变 UI，不改变资源身份。

旧同名资源混合的累计浏览和下载无法可靠拆分。迁移保留它们为历史记录，不能复制到每张新资源或平均分配。已有用户关系跟随原 `source_path`，缺失同名资源补入目录后独立计数。

## 实时读取与快照

详情通过 `image_stats_with_asset_key` 按完整键直接读取四项汇总；操作成功后刷新。未知/失败显示 `—`，服务端明确零显示 `0`。详情中的零值不代表整个系列没有启用统计。

列表与导出使用 `get_stats_page` 稳定游标分页到空页，校验总数、周/月边界和规范键。schema 2 快照包含 `rowCount`、`exportedAt`、`periodStartedAt`、`weekStart`、`monthStart` 及所有计数。任一系列失败时不替换整套旧快照。

页面跨周/月后使旧期间排名失效；新快照就绪后恢复。列表快照与详情实时数据可能有时间差。

## 热门标签

配置见 [hotTags.js](../src/utils/config/hotTags.js)，生成逻辑见 [export-hot-tags.js](../scripts/export-hot-tags.js)。

- 候选来自近 90 天完整元数据，无互动新图也参与；不是历史浏览 Top 500。
- 单图分数为 `(1 + min(log(1 + views + 3 × downloads) / log(101), 1)) × 2^(-上传天数 / 30)`，再按标签累加。
- 累计互动最多让基础分翻倍，时间权重每 30 天减半；无法明确对应资源的历史混合计数不复用。
- 它衡量近期内容与已有累计互动，不是“近 90 天新增互动”，也不是搜索词频。
- 桌面/手机/头像分类标签进入分类筛选；Bing 单图标签保留日期资源身份，月份和历史年份按各自语义加载。

## 历史迁移

主体为 [20261109_statistics_v2.sql](../scripts/migrations/20261109_statistics_v2.sql)，依赖 `stats_asset_mapping` 和 `stats_asset_catalog` 暂存表，不能直接单独执行。

```sh
node "scripts/prepare-statistics-migration.js" "<完整元数据目录>" "<证据输出目录>"
```

证据目录必须先有只读导出的 `assets-before.json`，字段为 `asset_key,series,filename,source_path,status`。准备脚本生成具体 SQL 与映射清单，不直接操作数据库。

完整迁移校验资产路径指纹，在非公开 schema 备份资源、统计与用户关系；外键更新级联保留数据，累计浏览/下载须与备份一致。它还引入事件与每日统计、分页 RPC、规范身份约束和敏感资料列保护。

已完成统计 v2 的数据库不要重复执行这份迁移。新建数据库也不能仅运行旧初始化脚本就视为兼容当前前端；应核验当前所需对象、权限和关系汇总触发器。旧表及备份的删除属于单独维护操作，本次文档整理不会执行。
