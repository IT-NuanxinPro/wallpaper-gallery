# 壁纸体验与设备能力设计

> 最终范围更新（2026-11-10）：用户取消“设备”和“发现筛选”两组扩展功能。设备适配、场景预览、颜色/比例/风格/用途筛选及相关索引已移除。下文对应任务为历史设计，不属于最终版本；最终发布范围以 docs/releases/v5.2.0.md 为准。新增网页与客户端独立更新通知。

用户已确认上一轮建议中的前五项优化及三个新增方向。本次交付这八项，不扩展游客收藏或新的推荐计分数据库。

## 范围与验收

1. 首屏：压缩公告和热门区，桌面和手机默认紧凑；保留展开、筛选、焦点与减弱动态效果。1280×720 桌面首张壁纸顶部目标不超过 380px。
2. 加载与下载：原图增加受限同源入口、可取消的超时与备用来源；裁剪加载失败可重试且保留尺寸选择；下载失败可重试且不错误计数。旧图片请求不得覆盖新选择。
3. 搜索：建议与结果使用同一个文本匹配函数，覆盖标题、文件名、分类、标签、关键词、描述；提供颜色、比例、风格和用途筛选。颜色从本地图床缩略图分析得到，缺失颜色不得伪造。索引在同步后生成，按稳定资源身份关联。
4. 连续浏览：上下张只在当前已筛选排序的结果中导航；最多预加载相邻两张预览；路由参数保存筛选与所选图片，刷新/返回恢复；按需恢复已展开数量和滚动位置。
5. 分享：每张图有 `/wallpaper/:token` 站内地址，token 为完整 asset key 的 UTF-8 base64url。分享打开独立详情、下载、相关内容，提供爬虫可读标题、描述、封面与 canonical；错误身份返回可恢复的未找到界面。
6. 设备适配：记住显示器/手机尺寸及自定义校正；按比例与实际像素匹配筛选；下载和裁剪使用所选设备。预览提供桌面图标/任务栏、手机锁屏遮挡；提供主体保护的建议裁剪与手动焦点/留白位置，基于可解释的图像显著区域估算，不声称模型识别人脸。
7. 原生桌面：静态图一键应用、从已有收藏建立轮换列表、定时/每日轮换、离线缓存、停止轮换、恢复上一张。Windows/macOS 实现原生设置；Linux 对支持的桌面环境探测并清晰报告不支持。进程退出后不会继续轮换，托盘运行时持续轮换。需明确用户启用，不自动开启或修改登录启动。
8. 专题：维护具名精选清单与电脑/手机配套分组；展示真实作者/来源字段，缺失时标明未提供，不臆造授权。入口紧凑，独立专题页展示精选内容、适用设备及相关推荐。

## 数据与边界

- 用户截图追加要求：筛选栏数量与控件对齐，消除数量居中而筛选靠右、发现筛选独占空白行的问题。容器按可用宽度换行，排序不可裁切；验收 1440/1280/1024/768/390px 及浏览器放大200%。新增设备控件一并适配，不增加首屏大型面板。

- 复用现有 asset key、统计、收藏和用户偏好；本次不需要数据库迁移。
- 本地图床目录为 `../nuanXinProPic`；数据可能采用已有 codec 编码。新增离线索引脚本读取现有数据和缩略图，生成颜色、设备尺寸和单图分享记录，部署流水线同步运行。
- 网站静态图入口只代理白名单仓库内的已验证路径；拒绝穿越、任意 URL、SVG、HTML 和超限响应，超时覆盖响应体。
- 原生 IPC 仅接受壁纸站来源与白名单图片 URL，限制重定向、内容类型、字节数、队列长度和轮换间隔；文件存入应用缓存目录，外部输入不可控制命令或任意本地路径。
- 原生操作结果确认后才显示成功；设置壁纸不冒充下载事件。切图、取消、退出和重入均有明确状态。
- UI 延续现有颜色和组件，中文用户文案；网站注释保持中文，Pake 源码注释使用英文。

## 验证与发布边界

功能开发在当前工作目录完成，按用户约束不自动创建分支、不提交或推送。用户此前对 v5.1.2 的发布已完成；本轮新功能发布需在全部可审阅后确认。不得在验证中上报真实互动统计或无提示更换用户系统壁纸。

验证包括核心逻辑回归、构建、源码 lint、桌面/手机浏览器关键流程，以及原生代码编译和可执行的纯逻辑测试。Windows/macOS 真实壁纸切换在未执行前不得声称通过。
