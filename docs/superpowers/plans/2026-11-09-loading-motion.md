# Loading 与交互反馈优化

用户指定视觉来源：邮箱项目的 `SoftLoading.vue` 与 `LoadingSurface.vue`，沿用四色四环2秒错峰SVG加载效果。

- [x] 统一LoadingSpinner、PageLoadingScene、ModalLoadingState、列表加载到共享SoftLoading；加载层绝对定位，主题适配，保持尺寸，短过渡与减少动态效果。
- [x] 卡片进入视口时只执行一次slide-up，使用共享IntersectionObserver，不以scroll逐项计算，不对所有卡片循环动画。改进触底追加与图片占位，确保加载前后尺寸稳定。
- [x] 桌面/手机各类图片弹窗加载、成功、失败共用固定图片区域；图片淡入，按钮忙碌与结果反馈完整，保留既有业务逻辑。
- [x] 补全共享按钮、链接、筛选、菜单、路由的按压/焦点/切换反馈；保持既有样式体系，避免transition:all及大范围昂贵模糊。
- [x] 验证电脑/手机、浅色/深色、慢图片、弹窗切图、滚动追加、减少动态效果；检查布局跳动和浏览器错误。
